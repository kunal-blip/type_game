# Type Game

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Deploy (Render)

This repository includes `render.yaml`, so you can deploy in one step:

1. Push this branch to GitHub.
2. In Render, choose **New +** → **Blueprint**.
3. Select this repository.
4. Click **Apply**.

Render will install dependencies, run `npm start`, and publish a live URL.

## Environment variables

- `JWT_SECRET` (required in production; auto-generated by Render blueprint)
- `PORT` (set automatically by Render)
